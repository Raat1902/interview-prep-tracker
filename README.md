# Interview Prep Tracker (Java)

A simple command-line tool to track your interview/LeetCode prep progress.

## Features
- Add problems (name, category, difficulty, date, status)
- View all problems
- Filter by category, difficulty, or status (exact match)
- Save/load using `problems.csv`
